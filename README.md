# 🧮 Math Quiz Game (C++)

A simple console-based Math Quiz Game written in C++ using Visual Studio.  
This project is intended for learning and practicing basic C++ concepts such as loops, functions, structs, enums, and input validation.

---

## 📌 Project Idea

Play a math quiz game where the player answers randomly generated math questions based on selected difficulty and operation type.

The player can:

- Choose the number of questions  
- Select the difficulty level (Easy, Medium, Hard)  
- Select the operation type ( + , - , * , / )  
- Answer randomly generated math questions  
- Get instant feedback for each answer  
- See final results at the end  
- Choose to play again  

---

## ✨ Features

- Random math question generation  
- Multiple difficulty levels  
- Multiple operation types  
- Input validation for numeric answers  
- Colored screen for correct and wrong answers  
- Sound alert for wrong answers  
- Final quiz summary  
- Pass / Fail result  
- Replay option  

---

## 🧠 Difficulty Levels

- Easy   → Numbers from small range  
- Medium → Numbers from 10 to 50  
- Hard   → Numbers from 50 to 100  

---

## ▶️ How to Run (Visual Studio)

1. Open Visual Studio  
2. Create a **Console App (C++)** project  
3. Paste the code into `main.cpp`  
4. Build the project  
   - `Ctrl + Shift + B`  
5. Run the project  
   - `Ctrl + F5`  

---

## ⚙️ Requirements

- Operating System: Windows  
- IDE: Visual Studio 2019 or later  
- Compiler: MSVC (C++)  

---

## ⚠️ Notes

This project uses Windows console commands such as:

- `system("cls")`  
- `system("color")`  

So it is intended to run on **Windows only**.
